# Логотип MIME-OS / EMLBox — текстовая концепция

## Идея

**Конверт, в котором видно содержимое.** Знак — контур RFC-822 конверта,
разрезанный по средней линии: из конверта видна «луковица» секций — стопка
слоёв (view, logic, state, assets), как они лежат внутри `.eml`-контейнера.
По нижнему краю знака — цепочка из четырёх звеньев: hash-chain дельта-лога.
Метафора двойная: контейнер читается любым почтовым клиентом (конверт) и
защищён от вмешательства (цепь).

## Геометрия

- Сетка построения — 32×32, знак вписан в квадрат со скруглением 12%;
- конверт: прямоугольник 26×18 с треугольным клапаном сверху (глубина 6),
  линия клапана — толщина 2;
- «луковица» секций: 4 вложенных скруглённых прямоугольника, смещённых
  вправо-вниз, толщина контура 1.5 — читается как список MIME-секций;
- hash-chain: 4 звена-овала по нижней кромке, соединённые перемычками,
  толщина 1.5;
- в favicon (16 px) остаётся конверт с двумя слоями и цепью из двух звеньев.

## Палитра

| роль | цвет | где |
| --- | --- | --- |
| фон | `#0D1117` | подложка |
| конверт | `#58A6FF` | контур конверта и клапан |
| секции | `#3FB950`, `#D29922`, `#8957E5`, `#DB61A2` | четыре слоя «луковицы» (по типу MIME-части) |
| hash-chain | `#6E7681` | звенья по нижней кромке |

Цвета секций намеренно разные: контейнер полиморфен — html, python, json,
бинарник живут в одном конверте.

## Типографика

Слово-логотип — **MIME-OS** капслоком, геометрический гротеск (Inter / Noto Sans),
вес 700, трекинг +3%; подстрока **/ EMLBox** — тем же начертанием весом 400,
строчными, через слэш. Альтернатива для CLI-контекста: `emlbox` моноширинным
(DejaVu Sans Mono) — так знак выглядит как команда, которую можно набрать.

## Что запрещено

- Не рисовать конверт закрытым (теряется сюжет «содержимое видно»);
- не выравнивать секции по центру (луковица смещена — это часть метафоры mmap-слоёв);
- не использовать «письмо с крылышками» и любые метафоры отправки: EMLBox —
  про хранение и контейнер, не про почтовую доставку.
